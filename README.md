# SHIFT RUNNER · 重力双轨

一个用 **SHIFT 翻转重力** 驱动的 3D 跑酷游戏。小球在双层霓虹隧道里自动向前冲刺，速度越来越快——你要在两层跑道之间来回跳跃，并且始终保持**小球颜色与所踩跑道颜色一致**，否则立即失败。

纯前端单文件实现，基于 Three.js，无构建步骤、无外部图片资源。

想本地运行的话，直接用浏览器打开 `index.html` 即可（同样需要联网加载 CDN 上的 three.js）。

如果浏览器拦截了本地模块加载，在目录下起一个静态服务器：


然后访问 <http://127.0.0.1:8000/index.html>。

## 核心规则

### 颜色必须与跑道一致

跑道只有两种颜色：**青** `#2ed3be` 和 **金** `#f2ae3c`。

判定发生在两个瞬间，**没有任何缓冲时间**：

1. **越过跑道分界线**：小球进入新的一段跑道时，颜色必须等于该段所在层的颜色。
2. **换层落地**：小球从一层弹到另一层、触面的那一帧，颜色必须等于目标层的颜色。

只要有一次不匹配，本局立刻结束。

> 关键技巧：判定只在「越线」和「触地」两个瞬间发生，所以可以提前换色——离开安全区之前就切好颜色是安全的。

### 跑道分界线

每一段跑道的两层各自独立取色，因此经常会出现「下层变金、上层还是青」的分叉。分界线会随速度自动拉长，保证高速时仍然有足够的反应时间。

## 玩法元素

### 障碍墙

红色斜纹墙封锁某一层的整段跑道。墙高 1.85，小球贴地时无法通过，必须在到达之前换到另一层。

### 光点与连击

金色光点悬浮在某一层的跑道面上，只有小球位于同一层时才能吃到。

- 每吃到一个 +10 分 × 当前倍率
- 连击倍率 = `1 + min(连击数, 20) × 0.1`，最高 **×3**
- 5 秒内没吃到新的光点，连击清零
- 漏吃不会清空连击（避免逼玩家为了连击去送死）

### 断裂跑道

第二阶段起出现。整层跑道直接消失，断口处有一条红色警示条。如果小球所在层恰好是断开的那层，当帧判定「跑道断裂」。

### 加速带 / 弹跳板

第三阶段起出现，贴在跑道面上的发光踏板：

- **亮金色加速带**：踩到后 1.15 秒内速度提升 38%，速度条与镜头 FOV 同步变化
- **紫色弹跳板**：强制翻转重力，把小球弹到另一层，并额外给一次初速

### 关卡阶段

每 **400 米** 进入新的阶段，屏幕中上方弹出阶段横幅：

| 阶段 | 名称 | 解锁内容 |
| --- | --- | --- |
| 1 | 热身 | 换色 + 障碍墙 + 光点 |
| 2 | 断裂 | 断裂缺口 |
| 3 | 加速 | 加速带 |
| 4 | 弹跳 | 弹跳板 |
| 5 | 极限 | 全部机制，速度接近上限 |

## 计分与记录

- **距离**：主指标，同时作为 BEST 记录存入 `localStorage`
- **得分**：只有光点提供，受连击倍率影响
- **最高连击**：结算页展示

结算页显示本局距离、历史最佳、得分与最高连击。

## 技术实现

- **Three.js r160**，通过 import map 从 jsDelivr 加载
- **2.5D 侧视镜头**：相机在跑道侧上方 `(12.8, 2.1, 10.4)`，望向隧道纵深；近侧墙移除以免遮挡视线
- **小球**：径向渐变精灵（半透明，能看到后方跑道）+ 外层光晕 + 偏移高光点；纵向运动是阻尼弹簧，触面时按冲击速度压扁、回弹时过冲，形成果冻质感
- **尾迹粒子**：34 个精灵粒子环形复用，按间隔从球身后发射，随时间渐隐收缩，颜色跟随小球
- **赛道段对象池**：按速度向前生成、相机后方回收复用，长时间运行不掉帧
- **程序化纹理**：侧壁网格、障碍斜纹、球体渐变、光晕均由 Canvas 实时绘制，零外部图片
- **音效**：WebAudio 实时合成，无音频文件
- **画面效果**：自发光材质、泛光叠加、扫描线、暗角、相机震动、加速 FOV

## 可调参数

主要参数集中在脚本开头的 `CFG` 对象：

```js
const CFG = {
  halfW: 3.6,        // 隧道半宽（跑道宽度 = 7.2）
  halfH: 3.0,        // 隧道半高（上下两层相距 6）
  ballR: 0.9,        // 小球半径
  baseSpeed: 15,     // 初始速度
  maxSpeed: 40,      // 最高速度
  accel: 0.95,       // 每秒加速量
  barrierH: 1.85,    // 障碍墙高度
};
```

其他常用调参位置：

| 想改什么 | 位置 |
| --- | --- |
| 开局安全段数量 | `state.safeCount = 6` |
| 各玩法出现概率 | `createSegment()` 中的 `Math.random() < 0.xx` |
| 阶段长度 | `state.distance / 400` |
| 连击超时时间 | `pickOrb()` 中的 `state.comboTimer = 5` |
| 加速带效果 | `state.boostTime = 1.15` 与 `spd` 的 `1.38` |
